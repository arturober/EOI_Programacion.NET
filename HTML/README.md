# Manual de HTML desde cero

Este repositorio reúne y organiza un **manual de HTML dividido en 10 unidades**, pensado especialmente para estudiantes que están empezando a crear páginas web.

El curso comienza con los conceptos más básicos, como la estructura de un documento HTML, y avanza progresivamente hasta la creación de tablas, contenido multimedia y formularios completos.

El objetivo principal es aprender HTML de forma práctica, clara y ordenada, utilizando ejemplos sencillos, ejercicios propuestos y pruebas de autoevaluación.

---

## ¿Qué es HTML?

HTML significa **HyperText Markup Language** o **Lenguaje de Marcado de Hipertexto**.

Es el lenguaje que se utiliza para definir la estructura y el contenido de una página web. Con HTML podemos indicar al navegador qué elementos debe mostrar, por ejemplo:

* Encabezados.
* Párrafos.
* Enlaces.
* Listas.
* Imágenes.
* Tablas.
* Vídeos y audios.
* Formularios.

HTML no se utiliza para programar el comportamiento de una aplicación, sino para **organizar y dar significado al contenido de una página web**.

---

## ¿A quién está dirigido este manual?

Este material está pensado para:

* Estudiantes que nunca han creado una página web.
* Personas que están empezando a estudiar desarrollo web.
* Alumnado de ESO, Bachillerato o Formación Profesional.
* Docentes que necesiten materiales introductorios de HTML.
* Cualquier persona que quiera repasar los fundamentos de HTML.

No es necesario tener conocimientos previos de programación.

---

## Objetivos del manual

Al completar las diez unidades, el estudiante será capaz de:

* Crear documentos HTML correctamente estructurados.
* Utilizar etiquetas y atributos.
* Organizar contenido mediante encabezados y párrafos.
* Aplicar formato semántico al texto.
* Crear enlaces entre páginas y secciones.
* Construir listas ordenadas, no ordenadas y descriptivas.
* Insertar imágenes y añadir información accesible.
* Representar información mediante tablas.
* Incluir vídeo, audio y contenido externo.
* Crear formularios con distintos tipos de campos.
* Organizar formularios complejos de forma semántica.
* Escribir código más claro, ordenado y accesible.

Para aprovechar mejor el manual, se recomienda seguir estos pasos en cada unidad:

1. Leer la explicación teórica.
2. Escribir manualmente los ejemplos.
3. Guardar el documento con extensión `.html`.
4. Abrir el fichero en un navegador.
5. Modificar el código y observar los cambios.
6. Completar los ejercicios propuestos.
7. Revisar el código y corregir los errores.
8. Realizar el test de la unidad.

Escribir el código manualmente ayuda a recordar las etiquetas y a comprender mejor la estructura de los documentos.

# Ejemplo mínimo de una página HTML

```html
<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi primera página web</title>
</head>
<body>
  <h1>¡Hola, mundo!</h1>
  <p>Esta es mi primera página creada con HTML.</p>
</body>
</html>
```

Guarda el código en un fichero llamado `index.html` y ábrelo con tu navegador.
